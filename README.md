# Outside the Lines

**Tagline:** Because everyone's journey is different.

## Vision

Build a personalized learning and productivity platform that helps people create their own learning journey, stay consistent, organize knowledge, track progress,resume adding space for various roles and maintain mental well-being without feeling overwhelmed.

## Problem

Learning resources, notes, planners, calendars and trackers are scattered across multiple tools, reducing consistency.

## Solution

A single personalized workspace that adapts to each user's goals, skills, study plan and progress.

## Target Users

Students, job seekers, career switchers, developers, data analysts, competitive exam aspirants and lifelong learners.

## Core Modules

Authentication, Dashboard, Journey, Skills, Planner, Notes, Progress Tracking, Reflection, Mental Well-being, Focus Mode.

## Key Features

* Custom journeys and skills
* Daily/weekly/monthly planner
* Revision notes
* Interview notes
* Searchable notes
* Streaks
* Study analytics
* Mood tracking
* Gamification
* Dark/light mode
* Responsive colorful UI
* Smooth animations


## Product Principles

* Personalization
* Simplicity
* Consistency over perfection
* Action-oriented design
* Enjoyable user experience

## Long-Term Vision

Become a personal learning operating system that adapts to every individual's unique journey.
